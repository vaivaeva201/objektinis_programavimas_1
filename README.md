# Pirmas_Laboratorinis

v.pradinė versija

Pragrama, kuri apskaičiuoja studentų galutinius įvertinimus pagal vidurkį arba pagal mediana ir rezultatus parodo lentelės formatu.
Vartotojas šioje versijoje išanksto turi žinoti kiek studentų ir kiek pažymių jis norės įvesti.
Duomenys įrašomi naudojant struktūrą ir vektorius.
